# Changelog

All notable changes to this project will be documented in this file.

The format is inspired by Keep a Changelog and follows Semantic Versioning.

---

## [1.0.0] - 2026-07-02

### Added
- Automatic extraction of CRMLS listing fields from the exported CSV.
- Streamlined workflow eliminating the external CSV extraction utility.
- Improved user interface with cleaner layout and updated instructions.
- Added project version tracking (`VERSION`).
- Added project changelog (`CHANGELOG.md`).
- Added `.gitignore` for runtime files and future development.

### Changed
- Updated Property Flyer Generator workflow to use the original CRMLS export.
- Refined templates and branding assets.
- Improved form usability and styling.

### Removed
- Requirement to preprocess CSV files before flyer generation.
- Legacy sample agent data from source control.

### Planned (v1.1)
- SQLite Agent Database
- Agent Administration Interface
- ZIP Upload & Automatic Extraction
- Image Selection Interface
- Castra Realty Marketing Studio branding
